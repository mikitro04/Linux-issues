# File AppImage

Spesso ci capita che alcune distribuzioni di Software possano non essere diffusi tramite repository contenenti file di installazione con estensione `.sh` ma con l'estensione `.AppImage`, come fare nel caso?

## Come installare un file AppImage?

Installare un file del genere è semplice, occorrono pochi passaggi:

1. Apri un terminale e digita

    ```bash
    sudo apt install libfuse2
    ```

2. Fai tasto destro sul file con estensione `.AppImage`, vai su **Proprietà** e infine spunta **`Eseguire come programma`**

Ora, una volta che cliccherai sul file, aprirà direttamente il software.

Se desideri aggiungere questa applicazione alla **griglia delle applicazioni** ti consiglio di guardare la mia guida [--> Qui](/general-Linux/Add_application_to_AppGrid.md).
